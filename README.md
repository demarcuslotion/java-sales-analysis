# Sales Analysis 
## Project Description
The program for this project analyzes monthly sales changes for a company that sells computers. 
It analyzes consecutive periods of months to find the period with the highest combined sales change. 

## Instructions (Compiling and Running)
Compiling:
javac src/SalesAnalysis.java

Running: 
java -cp src SalesAnalysis

## Program Output 
The program displays the starting month, ending month, and highest combined
sales change in dollars (millions).

## Issues or Limitations
The program does not allow user input and cannot read data from an external file.
